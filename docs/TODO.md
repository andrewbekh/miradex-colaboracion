# Що треба отримати від клієнта

На сторінках замість цих даних стоять нейтральні плейсхолдери. Тут зібрано все, що треба замінити перед запуском.

## Контакти й технічне
- Телефон Іспанії: зараз `+34 900 000 000` у `src/data/site.ts` (хедер, футер, фінальна форма).
- Номер WhatsApp: поки його немає, кнопки WhatsApp ведуть на `#whatsapp`. Вказати в `site.contacts.whatsapp` у форматі `34XXXXXXXXX`.
- Email B2B: зараз `hello@miradex.com` з miradex.partners, треба підтвердити іспанську адресу.
- Endpoint форми або CRM: `site.formEndpoint`. Поки форма працює в демо-режимі й пише дані в консоль.
- Текст згоди RGPD і посилання на політику конфіденційності: `site.privacyUrl`.
- URL основного іспанського сайту для пунктів хедера й «Ver catálogo»: `src/data/nav.ts`.
- Назва пункту меню: Colaboración / Profesionales / Para empresas (`site.navLabel`).

## Комерція
- Діапазони для поля «Volumen aproximado» (погонні метри або €). Зараз там якісні варіанти: тестове замовлення, регулярні замовлення, великий обʼєкт, ще не знаю.
- Правила захисту клієнта чи проєкту: які дані потрібні для реєстрації, коли захист вмикається, на який строк, що робити при подвійній реєстрації і з тендерами. Зараз у FAQ загальна відповідь.
- Чи можна публікувати цифри: відсотки знижок, реферальні 3-5% / 5-10%. Зараз на сторінках жодних цифр немає.
- Бізнес MIRADEX: чи є вхідний внесок або мінімальна закупівля (питання прибрано з FAQ, доки немає відповіді), орієнтовний бюджет запуску, фінансова модель запуску.
- Чи додавати «ni una franquicia» до тези «No somos una startup».

## Контент
- Ролики №1, №2, №3, №4, №6/№7, №11: зараз заглушки з постером.
- Фото й відео заводу в Румунії: у хабі в блоці «Producción» поки візерунок з підписом.
- Реальні об'єкти й B2B-кейси в Іспанії. Усі фото зараз з miradex.bg (`public/img/photos`).
- Цифри MIRADEX Bulgaria для картки «Modelo de referencia»: зараз `XX`.
- Формат навчання (онлайн чи наживо, тривалість, сертифікація монтажників).
- Логістика: чи є склад в Іспанії, мінімальне замовлення, вартість доставки, пакування.
- Остаточні іспанські назви напрямків: Vallas metálicas, Revestimientos metálicos, Sistemas de vallado.
- Сторінки секторів (13 шт., стратегія, розділ 7): у футері й хабі посилання поки ведуть на `#`.
